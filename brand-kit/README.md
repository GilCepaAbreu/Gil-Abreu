# CodeCraft Studio — Brand Kit

Paleta: azul-noite `#071522`, ciano `#27DBE8`, verde `#5DEA9B`, branco `#EAF7F7`.

- `logo-primary.svg`: logótipo para fundos claros.
- `logo-reverse.svg`: logótipo para fundos escuros.
- `logo-mark.svg`: símbolo isolado para avatar, favicon, marca de água e ícone de aplicação.
- `business-card-front.svg` e `business-card-back.svg`: cartão de visita 85 × 55 mm, escalável para impressão.
- `banner-website.svg`: banner horizontal para site, propostas ou apresentações.
- `banner-linkedin.svg`: dimensões de cabeçalho LinkedIn, 1584 × 396.
- `social-square-template.svg`: publicação 1080 × 1080.
- `social-story-template.svg`: story/reel cover 1080 × 1920.
- `banner-background-wide.png` e `social-background-square.png`: fundos sem texto para reutilização.

Os ficheiros SVG são editáveis em Figma, Illustrator, Inkscape e, na maioria dos casos, Canva. Antes de enviar para impressão, confirma a conversão para CMYK com a gráfica.
